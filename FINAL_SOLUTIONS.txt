========================================
SDM-Economy 构建失败 - 终极解决方案
========================================

错误: "Failed to remap minecraft"
这是 Architectury Loom 的 Minecraft 映射缓存损坏问题。

========================================
解决方案 1: 终极缓存清理（推荐尝试）
========================================

运行 ULTIMATE_FIX.bat

这会：
1. 杀死所有 Java 进程
2. 删除整个 %USERPROFILE%\.gradle\caches 文件夹
3. 删除所有 Loom 缓存
4. 重新下载所有依赖（需要 20-30 分钟）

注意：
- 需要稳定的网络连接
- 可能需要以管理员身份运行
- 暂时关闭防火墙/杀毒软件

========================================
解决方案 2: 手动删除缓存文件夹
========================================

如果脚本运行失败，手动操作：

1. 按 Win+R，输入：%USERPROFILE%\.gradle
2. 删除以下文件夹：
   - caches
   - loom-cache
   - wrapper

3. 回到 SDM-Economy-1.20.1 文件夹
4. 运行：gradlew.bat clean :forge:build

========================================
解决方案 3: 检查环境
========================================

1. 确认 JDK 17 安装：
   打开 CMD，运行：java -version
   应该显示：openjdk version "17.x.x"
   
   如果不是 17，下载安装：
   https://adoptium.net/temurin/releases/?version=17

2. 确认 JAVA_HOME 环境变量：
   CMD 运行：echo %JAVA_HOME%
   应该指向 JDK 17 安装目录

3. 检查网络连接：
   - 能否访问 https://maven.architectury.dev
   - 能否访问 https://libraries.minecraft.net

========================================
解决方案 4: 使用原版项目手动添加代码（备选）
========================================

如果所有方法都失败，可以：

1. 从 GitHub 克隆原版 SDM-Economy:
   git clone https://github.com/SagaDeoMissTeam/SDM-Economy-1.20.1

2. 从我的项目复制这些文件到原版项目：
   - forge/src/main/java/net/sixik/sdmeconomy/forge/vault/
     (包含 SDMVaultEconomy.java 和 VaultIntegration.java)

3. 修改 forge/src/main/java/net/sixik/sdmeconomy/forge/SDMEconomyForge.java
   添加代码（见 VAULT_INTEGRATION_1.20.1.md）

4. 修改 forge/build.gradle 添加 Vault API 依赖
   (见 VAULT_INTEGRATION_1.20.1.md)

5. 在原版项目上构建

========================================
常见问题
========================================

Q: 为什么一直失败？
A: Architectury 需要下载和处理大量的 Minecraft 映射数据，
   过程复杂且容易因网络/缓存问题失败。

Q: 需要多长时间？
A: 首次构建：20-30 分钟
   后续构建：2-5 分钟

Q: 可以跳过构建吗？
A: 不行，必须构建才能生成可用的 JAR 文件。
   但我可以提供预构建版本。

========================================
下一步建议

2. 如果还是失败，检查 JDK 版本
3. 尝试关闭防火墙后重试
4. 如果都不行，考虑解决方案 4（手动添加代码到原版）
5. 最后选择：让我帮你构建
